# Déploiement du Pack Excellence RLC

## Fichiers

- `app.py` : application Streamlit.
- `requirements.txt` : dépendances Python utilisées par Streamlit Cloud.

## Déploiement sur Streamlit Community Cloud

1. Créez un dépôt GitHub et ajoutez `app.py` et `requirements.txt` à sa racine.
2. Connectez-vous à Streamlit Community Cloud avec GitHub.
3. Créez une nouvelle application en choisissant le dépôt, la branche, puis `app.py` comme fichier principal.
4. Lancez le déploiement et ouvrez l’URL fournie par Streamlit.

Pour un lancement local, installez les dépendances avec `pip install -r requirements.txt`, puis lancez `streamlit run app.py`.
