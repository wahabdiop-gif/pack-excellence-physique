# SunuLabo PC

Mini-application de révision en physique-chimie : parcours par niveau, trois calculateurs, quiz, progression locale et fonctionnement hors ligne après le premier chargement.

## Déploiement GitHub Pages

1. Placez les fichiers du projet à la racine du dépôt GitHub.
2. Dans **Settings → Pages**, choisissez **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis enregistrez.
3. Attendez la fin de la publication dans l’onglet **Actions**. L’adresse prendra la forme `https://<nom-utilisateur>.github.io/<nom-du-depot>/`.
4. Ouvrez le lien une première fois avec Internet pour mettre en cache les fichiers de l’application.

## Fonctionnalités

- Parcours Seconde, Première et Terminale avec exemples de contexte sénégalais.
- Calculateur solaire, fréquence propre RLC et dilution.
- Quiz à cinq questions avec mémorisation locale du meilleur score.
- Application installable et ressources essentielles mises en cache par le service worker.
- Aucun compte élève et aucune donnée envoyée à un serveur.

Les exemples sont des supports de révision. L’enseignant adapte les valeurs et vérifie l’alignement avec le programme de sa classe.
